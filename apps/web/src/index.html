Get Started in 2 Minutes

Clone, configure, and run. No complex setup required.

terminal
# Clone the repository
$ git clone https://github.com/husteno-o/git-discord-bot.git
$ cd git-discord-bot
# Install dependencies
$ bun install
# Configure your bot token
$ cp .env.example .env
# Start the bot
$ bun run start
